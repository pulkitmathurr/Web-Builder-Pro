# Background Music — preset track files

Drop the actual `.mp3` files here, named exactly as referenced in
`frontend/src/constants/musicTracks.js`:

- `calm-piano.mp3`
- `uplifting-strings.mp3`
- `soft-ambient.mp3`
- `gentle-morning.mp3`

Source only royalty-free / CC0 / CC-BY tracks you're cleared to redistribute on a
commercial site (e.g. YouTube Audio Library, Pixabay Music, Free Music Archive with
a CC0 license). If you use a CC-BY track, keep a note of the required attribution
somewhere (e.g. this file) — CC-BY needs credit even though it's free to use.

Until these files exist, the Background Music admin tab will show tracks whose
preview/playback 404s — add the files before enabling the feature for any school.
